# Prácticas de PHP

Ejercicios de PHP y fundamentos de desarrollo web.

## Contenido

- `array.php`: práctica con arreglos.
- `poo.php` y `poo2.php`: ejercicios de programación orientada a objetos.
- `index.html`: página de entrada del repositorio.

## Explorar localmente

Abrí la carpeta con un entorno que ejecute PHP para probar los archivos `.php`. Las páginas HTML se pueden inspeccionar directamente en el navegador.
